# 技术分析教程支持资料

正文：`content/research/technical-analysis.md`。材料整理日：2026-09-23。

## 数据与复现

全部价格、OHLC 和成交量由 `scripts/research/technical-analysis.py` 确定性构造，不对应证券、账户或真实成交。数字横轴表示教学交易期。正文与 manifest 的 `data_as_of` 是这套教学材料的整理日期，不是真实行情的截止日期。

- `--export-data`：导出本目录的教学 CSV 和 `readings.json`，供逐项核对。没有网络访问、随机数或当前时间依赖。
- `--summary`：只在标准输出打印关键读数。
- `make analyze REPORT=technical-analysis`：只生成该教程的 Plotly 快照。普通站点构建不运行分析、不改写正文。
- 原对话的关键价格结构保留；未取得原始完整序列的指标读数由新序列重算，不声称逐点复制原图。

## 图表约定

最终载体为现有 VuePress `PlotlyChart`。沿用仓库字体和白底；价格用深灰，辅助序列用蓝、金、橙及不同线型；正负柱用深色与浅色并保留零轴，不依赖红绿辨识。图名、教学属性和单位由相邻正文、轴与图注给出，不新增品牌装饰。最终在桌面和 390px 宽页面检查，图表不得只依赖悬浮操作传达核心结论。

| chart ID | 问题与支持的理解 | 形式与数据粒度 |
| --- | --- | --- |
| candle-paths | 同一组四价不能确定高低点发生顺序 | 一根蜡烛与两条各四节点的构造路径；节点是特意简化的路径，不是实测分时样本 |
| market-structure | 上升结构受损后，下降结构还需要后续高低点确认 | 逐期折线，标出关键波段点和旧低点 |
| breakout-retest | 回踩深度和量能应在同一段行情中比较 | 30 根日 K 线与共享横轴的成交量柱 |
| moving-averages | 近期回落可以与较长均线上行同时存在 | 150 期收盘价及 SMA20、EMA20、SMA60 |
| volume-profile | 历史成交集中于哪些价格；价值区描述成交占比 | 15 档横向柱，每档宽 2，合计 10,000 份；按价格顺序排列 |
| bollinger-bands | 带宽反映近期价格分散，触轨与沿轨可同时存在 | 100 期价格及 SMA20±2 倍价格标准差 |
| fibonacci-anchors | 同一价格在两个波段下有不同回撤深度 | 与均线相同的价格序列；第 132 期确认局部高点后显示两组 50%、61.8%、78.6% 参考位 |
| momentum-price | 第二次创新高的推进更慢且包含更多回落 | 155 期价格及 EMA12、EMA26；突出第 100、149 期 |
| momentum-macd | 创新高时，两条 EMA 的距离可以更小 | 同一序列的 DIF、DEA 与带符号柱体 |
| momentum-rsi | 创新高时，上涨相对下跌的优势可以更小 | 同一序列的 RSI14，固定 0—100 轴 |
| breakout-paths | 同一次越界可以接续不同结果 | 第 21 日前共同历史，之后 A、B 两条无概率的备选情景 |
| pattern-comparison | 形态名称对应哪些高低点与边界 | 双顶、头肩顶、上升三角形、上升楔形四面板；形成过程与后续越界示例用线型区分 |
| timeframe-weekly | 较大结构仍保留下降特征 | 同一小时数据聚合的 42 周 K 线，标记前高及最近反弹范围 |
| timeframe-daily | 周线反弹内部形成日线上升 | 同一数据最近 43 天，保留周线和日线三个关键区域 |
| timeframe-hourly | 日线回调内部包含小时下降 | 同一数据最后 20 小时，当前价格与日线、周线一致为 108 |

不同案例相互独立。Volume Profile 由明确的价档成交样本汇总，不从日线 OHLC 猜测价内成交量；它不能用来解释均线或动量案例的资金行为。

## 计算口径

- SMA：收盘价的完整 N 期窗口均值，窗口不足时留空。
- EMA：首个价格为初值，此后 `alpha=2/(N+1)` 递推；不使用未来观测。动量例前 80 期为预热背景。
- Wilder 平滑：首 N 个有效观测的算术均值初始化，随后 `alpha=1/N` 递推。RSI 的首个有效值需要 N 个价格变化，即 N+1 个价格。
- TR：高低差、最高价到前收盘距离、最低价到前收盘距离三者取最大；首期缺前收盘，按高低差计。ATR14 对 TR 使用 Wilder 平滑。
- RSI：所有时期分别记录正变化与负变化绝对值；`100*U/(U+D)`。只有上涨时为 100，只有下跌时为 0；从开始完全不动、分母为零时留空。已有非零 U、D 后完全横盘，比值保持不变。
- MACD：EMA12−EMA26 为 DIF，DIF 的 EMA9 为 DEA，柱体为 DIF−DEA。EMA 与信号线均按上述首值初始化。
- 布林带：SMA20 与收盘价格的 20 期总体标准差（`ddof=0`），上下各两倍。历史收益率波动率的独立算例采用对数收益率与 252 交易日平方根年化，不把布林带标准差混用为收益率波动率。
- Fibonacci：线性价格，上涨回撤位 `H-r*(H-L)`，图中锚点统一使用收盘价；没有把高低价锚点与收盘价指标混用。
- Fibonacci 确认：局部高点收盘严格高于左右各两期，第 130 期的 140 在第 132 期收盘后确认；两组水平线均从第 132 期起显示，不回画到第 80／110 期。图中向右延伸至第 156 期只表示固定参考水平，价格序列仍结束于第 150 期。
- 形态对照：`patterns.csv` 保留四条短路径；每条最后一个节点为补充的后续越界示例，其余为形成过程。横轴节点只表示先后，各面板独立价格轴，不用于比较速度或历时；边界与颈线是回顾性的形态说明，不是实时识别输出。
- Profile：`[100,102)` 至 `[128,130)` 共 15 档，样本全部位于档中点。价值区从最大档起，每次加入紧邻区域且成交量较大的一档，并列时优先较低档，直到累计至少 70%。这是本教程明确选定的连续扩展规则，不保证与每个平台一致。
- 多周期：每四个小时构成一个教学日，每五日构成一周；840 小时 → 210 日 → 42 周。各级开高低收按 first/max/min/last 聚合。小时开盘取前收，最高最低取开收极值，不添加额外影线。第 0 小时的 148 只作为初始开盘依据，不作为第 1 根 K 线。输入必须完整分组，不把未结束周冒充完整周。日线图展示第 168—210 日，小时图展示第 821—840 小时，横轴重标为 1—20；没有成交量数据。
- 多周期价格锚点与小时尾段沿用完整分享对话的教学构造。图中标注为回顾性结构说明，不生成实时拐点信号；周线最后一根最高 112、最低 106.8、收盘 108。横轴是教学周期，不套用实际市场日历。
- Stochastic 独立算例为未平滑快速 %K，窗口高低差为零时未定义；%D 的三期 SMA 与慢速版本仅作概念说明，不与 RSI 的 Wilder 平滑混用。
- 风险与估值算例均为虚构算术，普通执行成本按每份往返 1 元处理；数量向下取整，不把跳空损失纳入普通成本后声称风险有上限。没有真实账户、证券、操作计划或策略回测。
